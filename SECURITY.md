# Security

Please report security problems in the web app privately, through
[Report a vulnerability](https://github.com/OAndrija/homesilo-server/security/advisories/new)
on the server repository. The server's [SECURITY.md](https://github.com/OAndrija/homesilo-server/blob/main/SECURITY.md)
explains what's in scope and what happens next. Please don't open a public issue.
